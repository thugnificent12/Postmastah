# Il Direttore dell'Ufficio

Gioco gestionale di ufficio postale (fantasia). © 2026 G-Loc Prodz

**ATTENZIONE:** questo è un gioco di fantasia. Nomi, personaggi, luoghi ed eventi sono frutto dell'immaginazione dell'autore o sono usati in modo fittizio. Qualsiasi somiglianza con fatti reali o persone vere, è puramente casuale.

## Come giocare
Apri `index.html` nel browser (telefono o computer). Il gioco salva da solo.

## Su internet (GitHub Pages)
Repository → Settings → Pages → "Deploy from a branch" → branch `main`, cartella `/ (root)`.
Poi apri l'indirizzo che compare.

## App Android
Apri l'indirizzo del sito con Chrome sul telefono → menu (tre puntini) → "Installa app".
Per un file `.apk`: pwabuilder.com.
